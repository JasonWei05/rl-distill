The fitted curve

Every fitted line on this page is this curve. Each model size has one set of A, B, m0 and m1, shared by all of its runs, and each run starts from its own Rref.

a(C) = Rref + A − Rref1 + (Cmid / C)B
log10 Cmid = m0 + m1 log10 pass@16, so Cmid = 10m0 · pass@16−γ with γ = −m1

The form and the way it is fitted follow Khatri et al. (2025), The Art of Scaling Reinforcement Learning Compute for LLMs, eq. 1, and Bailey et al. (2026), Scaling Self-Play with Self-Guidance, eq. 1 and App. A: a sigmoid in log compute whose starting level is set to an observed value rather than fitted, with the earliest points left out. Two choices are this study's own: Rref is a mean over a window of steps rather than one point, and A, B and a power law for the midpoint in the start's pass@16 are shared by all runs of a size. The fit clips A − Rref at zero; no run here starts above A. In the code this is form PAPER of rl_curve_family.py.

How it is fitted: all runs of one size at once, by bounded least squares (SciPy least_squares, the best of 13 starting points). Each run counts equally: its residuals are divided by the square root of its number of points. The free parameters are A, B, m0 and m1; Rref is fixed per run. A held-out test refits without one start and predicts that start's seed-0 run from its own Rref.

Data and method

Two sizes of the text-maze policy, S and L, are trained with GRPO from frozen starting checkpoints matched in pass@1 across the sizes; a start is named by that pass@1. Each start has two RL seeds per size. Dev is goal_reached pass@1 on the dev mazes, the mean of 16 samples per maze, logged every 10 steps; compute is cumulative training PFLOPs from each run's FLOPs ledger.

The family fit is described under The fitted curve, above. The per-run Cmid in the midpoint chart refits each run alone, with A and B fixed at its family's values.

The 10%, 1% and 0.1% starts come from the earlier budget study. This round adds the 5.5%, 3% and 0.3% starts, the second L seeds at 1% and 0.1%, and a 1% S seed-1 run to the compute ceiling that replaces the shorter earlier one. Curves, fits and logs are in the budget-study repository's extra folder; checkpoints are in tailrl-text-maze-extra-levels.
